# 渲染后自查清单

在**看过 PNG 渲染结果之后**逐条检查。任何一条"否"都要修改或在交付说明中解释。
把结果写进 `assets/readme/DESIGN.md` 的 `Review log`：`第 N 版 → 问题 → 修改`。

## A. 概念（最重要）

- [ ] **专属性**：把项目名换成另一个开源项目，这张图还成立吗？（成立 = 不合格）
- [ ] **3 秒识别**：不看文字，能认出画的是什么物件/场景吗？
- [ ] **证据**：主视觉里至少有一组来自项目真实输出/字段的内容，且字段名与源码一致？
- [ ] **标志性细节**：概念物件的 2–3 个标志性细节都画出来了吗？（例：票据的撕口、印章、条码）

## B. 张力

- [ ] 至少有一处**极端尺度对比**（最大字号 : 最小信息字号 ≥ 6:1）
- [ ] 至少采用了风格卡 `tension` 中 2 条规则
- [ ] 不是"所有元素居中、等距、等大"
- [ ] 强调色只用在 1–2 个真正关键的点上

## C. 可读性（按 GitHub 实际尺寸）

GitHub 桌面正文栏约 830px，移动端约 360px。

- [ ] 用 `render_preview.py --github` 渲染 830px 版本查看：所有承载信息的文字 ≥ 14px
- [ ] 360px 移动版：项目名与核心一句话仍可读
- [ ] 正文对比度 ≥ 4.5:1，标签 ≥ 3:1
- [ ] 文字不与图形重叠、不被裁切（有意出血的装饰除外）

## D. 深浅色

- [ ] 深色版是对概念的重新诠释，而不是反色
- [ ] 两版信息完全一致，没有一版缺字段
- [ ] 在 GitHub 深色背景（#0d1117）上，深色版的边缘不会"消失"或突兀

## E. 事实与工程

- [ ] 没有虚构的数字、徽章、用户、许可证
- [ ] 示例值（`owner/repo`、SHA）明显是示例，不会被误认为真实仓库
- [ ] `lint_svg.py` 0 error
- [ ] 文字已转路径，或字体栈有合理系统回退且已在交付说明注明
- [ ] 每张 SVG 有 `<title>`，README 中 `<img>` 有描述性 alt

## 常见第一版问题与改法

| 现象 | 改法 |
|---|---|
| 画面"干净但平庸" | 回到 4.3 重定概念；把真实证据放大成主体 |
| 看起来像模板 | 删掉所有不属于概念物件的装饰；加入标志性细节 |
| 标签看不清 | 字号按 `目标px / 0.65` 放大；减少标签数量而不是缩小字号 |
| 流程图像 PPT | 画出项目特有结构：闸口、回退、恢复分支；节点用真实命令名 |
| 深色版很闷 | 换"场景"而不是换颜色（白天纸张 → 夜间发光屏/荧光油墨） |
